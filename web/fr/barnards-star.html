Étoile de Barnard

L’étoile dont la position dans le ciel change le plus vite : 10.4 secondes d’arc par an, soit environ 1.7 pixel SPHEREx.

Les étoiles se déplacent aussi, mais bien plus lentement. De toutes les étoiles, c’est celle dont la position dans le ciel change le plus vite : moins de deux pixels de SPHEREx par an. Les numéros montrent ce que l’outil en tire.

Ce qu’il faut regarder

Les images parcourent trois visites en boucle : l’étoile saute chaque fois d’environ un pixel vers le nord, le long de la ligne pointillée. Son cœur est assez brillant pour saturer les détecteurs à courtes longueurs d’onde ; c’est donc D5 qui donne la vue la plus propre.
