Pulsating red giant (Mira variable) · M

R Draconis

A red giant that swells and shrinks, brightening and fading over about 245 days.

A red giant near the end of its life, swelling and shrinking every 245 days. Each image covers about one month. The star is so bright that it overloads the detectors, so the tool measures its outer glow instead. The brightness curve rises and falls with the pulse.

What to look for

Each image covers about a month. This star is so bright that its core saturates every detector, so the tool measures its faint outer glow instead. The brightness curve shows the pulse: brightest in July 2025, about half as bright that autumn, and climbing again in the latest images.

SPHEREx has 2,497 exposures of this spot, from April 24, 2025 to September 27, 2026.
